# Release Notes

### Internal: single source of truth for the PHP host-function surface ([#89](https://github.com/Folk-Project/folk-releases/issues/89))

**A maintenance/architecture release — no change to the PHP API, behaviour, or
configuration.** The extension exposes the exact same `folk_*` functions and
`Folk\Server` class as before; existing apps need nothing.

Previously the PHP-callable host functions lived in **two copies** that had to be
kept in sync by hand: the real `#[php_function]` definitions in `folk-ext`, and a
byte-for-byte **string codegen** duplicate inside `folk-builder` (which also had a
`has_grpc` gate that string-emitted the gRPC descriptor function — an ownership
inversion where the builder "knew" about a gRPC-specific function).

This release removes the duplication:

- **`folk-ext` 0.6.2** — adds `register_core_functions`, the single place that
  registers all 20 core host functions (`folk_call`, `folk_write_*`, `folk_read_*`,
  `folk_stream_*`, `folk_grpc_yield`, …). Both the standalone extension and the
  builder-generated module delegate to it.
- **`folk-plugin-grpc` 0.7.0** — owns its `folk_grpc_descriptors` PHP function
  behind a new opt-in `php-ext` Cargo feature (`register_php_functions`), instead
  of it being string-generated by the builder. Off by default; the plugin stays
  PHP-runtime-agnostic.
- **`folk-builder` 0.2.19** — no longer emits string copies of any function body.
  Its generated `get_module` calls `folk_ext::register_core_functions` and, when
  the gRPC plugin is present, the plugin's `register_php_functions` (the `php-ext`
  feature is enabled automatically). Adding a host function no longer means editing
  the builder.

**Why it matters:** each host function is now defined once, in the crate that owns
it. No more silent drift between the two copies, and no reviewer-hostile
string-generated Rust.

Validated end-to-end: the rebuilt `.so` exposes the identical function set (21
with gRPC, 20 without), and the full gRPC server-streaming + unary E2E suite
passes unchanged.

Prebuilt extension release `0.2.11` (folk-builder 0.2.19, folk-plugin-grpc 0.7.*,
folk-ext 0.6.2).
